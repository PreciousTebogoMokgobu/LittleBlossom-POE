## Part 2 Improvement
Following the feedback from Part 2, I have completely overhauled the website to ensure a professional, premium look.
- **External CSS:** Linked `css/style.css` to all HTML pages.
- **Layout:** Implemented CSS Grid and Flexbox to replace all old table layouts.
- **Responsive Design:** Added media queries for tablet and mobile devices.
- **Typography:** Used `rem` units and Google Fonts (Montserrat and Poppins).

## Part 3 Functionality & SEO
In Part 3, I added the following features to meet the rubric requirements:
1. **JavaScript Form Validation:** Added to `contact.html` and `enquiry.html` using `try/catch` blocks to validate user input before submission.
2. **Live Date and Time:** Added a `setInterval` function in `script.js` that updates the footer on all pages in real-time.
3. **Dynamic Search:** Added a live search filter on `services.html` that filters the service cards instantly.
4. **Interactive Lightbox Gallery:** Added to `index.html` so users can click images to view them full-screen.
5. **External Content Integration:** 
   - Embedded a Google Map on the `contact.html` page.
   - Embedded a YouTube video on the `index.html` page.
6. **Search Engine Optimization (SEO):**
   - Added Meta Descriptions, Meta Keywords, and Author tags to the `<head>` of all 5 pages.
   - Added descriptive `alt` text to all images.
